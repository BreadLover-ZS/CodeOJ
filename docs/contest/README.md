## 维护时先确认

- 新链路需应用 V001—V005 并启用对应开关；旧队列和旧报名协议按交接文档切换。
- MySQL 保存资格与结果事实；Redis 预留或 MQ 确认不代表业务完成。
- 对账与迟到错误处理都受原 epoch/revision 约束，不要重新读取新版本后继续旧操作。
- 本机功能、真实依赖、部署和压测分开验收；最新修复不会自动继承旧版本的全栈结论。
